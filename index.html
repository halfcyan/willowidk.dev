Open Source — Fyra Labs

I work with Fyra Labs, a small open-source team working on Ultramarine Linux, Terra, and Fyra Stack. Ultramarine Linux makes it easy to use Fedora Linux to Do Your Thing. Terra provides over 2,000 packages that Fedora doesn't, updated automatically. Fyra Stack is a new cloud hosting provider, focused on open-source, honest pricing, and doing cool shit.

I work on packaging for Terra and as a software engineer for Fyra Stack. I also help out with Ultramarine when there's work to be done.
